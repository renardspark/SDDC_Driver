### SDDC_Driver

# Windows driver setup

SDDC_Driver requires specific drivers to be installed to use your SDR.

1. Connect your SDR to your computer
1. device manager
1. In "other devices", check for a device named "WestBridge"
2. Right-click -> update driver
3. Select Browse my computer for driver software
4. Select from the list
5. Select WinUSB

6. run program

7. do the same with the device in "other devices" (here rx888 mkII)
